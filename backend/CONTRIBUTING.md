# Contributing to the VerifAI Backend

1. Start from the latest `main`.
2. Work on a feature branch.
3. Never commit secrets.
4. Keep API responses backward-compatible where practical.
5. Use parameterized SQL.
6. Add/update tests with backend behavior changes.
7. Run `npm run check` and `npm test` before opening a PR.
8. Document new endpoints in `API.md` and `docs/openapi.yaml`.
9. Open a Pull Request for review before merging to `main`.
